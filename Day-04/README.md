# Day 4 - Randomization and Lists

Day 4 of **100 Days of Code - Python Bootcamp**.

This day focuses on randomization, lists, list indexing, nested lists, and combining these concepts to build a simple **Rock Paper Scissors** game.

---

## 🎯 Day 4 Goals

By the end of Day 4, I learned how to:

- Use Python's `random` module
- Generate random numbers
- Select random items from a list
- Understand list indexing and offsets
- Add items to lists using `append()`
- Understand nested lists
- Identify and debug `IndexError`
- Combine lists, randomization, input, and conditional logic
- Build a Rock Paper Scissors game
