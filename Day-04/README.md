# 💡 Key Learnings
The most important lessons from Day 4 were:

### 1. Python lists are zero-indexed
The first element is at index `0`.

### 2. `append()` modifies a list
It adds a new item to the end of the list.

### 3. `random.choice()` selects a random list item
This is useful when building games and simulations.

### 4. IndexError usually means an invalid index
Always check the list length and valid indexes.

### 5. Nested lists require multiple indexes

For example:

```python
matrix[row][column]
```

### 6. Randomisation makes programs less predictable
This becomes especially useful for games such as Rock Paper Scissors.
